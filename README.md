# 📚 CourseMate AI — PDF Question-Answering Assistant

CourseMate AI is a **Retrieval-Augmented Generation (RAG)** application that lets you upload a PDF (lecture notes, textbook chapters, papers) and ask questions about it in plain English. Answers are generated **only from the document's content**, so the assistant won't make things up — if the answer isn't in the PDF, it says so.

---

## ✨ Features

- 📄 **Upload any text-based PDF** through a simple web interface
- 🔍 **Semantic search** over the document using vector embeddings
- 🤖 **Grounded answers** generated by an LLM using only the retrieved context
- 🚫 **Hallucination guard** — replies *"I could not find the answer in the document."* when the context has no answer
- 🔎 **Transparent sources** — view the exact chunks (with page numbers) used to produce each answer
- 💻 **Two ways to use it:** a Streamlit web app and a command-line chat

---

## 🧠 How It Works

```
PDF ──► Text extraction ──► Chunking ──► Embeddings ──► ChromaDB
                                                           │
Question ──► Embed query ──► MMR retrieval (top 4 chunks) ◄┘
                                   │
                                   ▼
                     Prompt (context + question)
                                   │
                                   ▼
                          Groq LLM ──► Answer
```

1. **Load** — the PDF is read page by page with `pypdf`, keeping page numbers as metadata.
2. **Chunk** — text is split with `RecursiveCharacterTextSplitter` (chunk size **1000**, overlap **200**).
3. **Embed & store** — chunks are embedded with `BAAI/bge-small-en-v1.5` and saved in a persistent **ChromaDB** store (`chroma_db/`).
4. **Retrieve** — for each question, **MMR (Maximal Marginal Relevance)** search returns 4 diverse, relevant chunks (`fetch_k=10`, `lambda_mult=0.5`).
5. **Generate** — the chunks and question are passed to a Groq-hosted LLM (`openai/gpt-oss-20b`) with a strict "use only the context" prompt.

## 🚀 Getting Started

### Prerequisites

- Python (see `.python-version` for the version used)
- A free **Groq API key** — get one at [console.groq.com](https://console.groq.com/)

### 1. Clone the repository

```bash
git clone https://github.com/shravya013/RAG-project---CourseMate-AI.git
cd RAG-project---CourseMate-AI
```

### 2. Create a virtual environment and install dependencies

Using `pip`:

```bash
python -m venv venv
source venv/bin/activate        # Windows: venv\Scripts\activate
pip install -r requirements.txt
```

Or using [`uv`](https://github.com/astral-sh/uv):

```bash
uv sync
```

### 3. Set up your API key

Create a `.env` file in the project root:

```env
GROQ_API_KEY=your_groq_api_key_here
```

> ⚠️ Never commit your `.env` file. It is already excluded via `.gitignore`.

## ▶️ Usage

### Option A — Web app (recommended)

```bash
streamlit run app.py
```

Then in the browser:

1. Upload a PDF.
2. Click **Create Vector Database**.
3. Type a question and click **Ask**.
4. Expand **View Retrieved Document Chunks** to see the supporting passages and page numbers.

### Option B — Command-line chat

First build the database from a PDF placed in `document loaders/` (update the file path inside `create_database.py` to match your PDF's name):

```bash
python create_database.py
```

Then start the chat:

```bash
python main.py
```

Type your questions at the `You:` prompt, and enter `0` to exit.

## ⚙️ Configuration

You can tune the pipeline by editing these values in `app.py` / `create_database.py` / `main.py`:

| Setting          | Default                    | Description                                   |
|------------------|----------------------------|-----------------------------------------------|
| `chunk_size`     | `1000`                     | Characters per chunk                          |
| `chunk_overlap`  | `200`                      | Overlap between consecutive chunks            |
| `model_name`     | `BAAI/bge-small-en-v1.5`   | Embedding model                               |
| `k`              | `4`                        | Chunks passed to the LLM                      |
| `fetch_k`        | `10`                       | Candidates considered before MMR re-ranking   |
| `lambda_mult`    | `0.5`                      | Relevance vs. diversity balance (0–1)         |
| LLM `model`      | `openai/gpt-oss-20b`       | Groq model used for answering                 |

## ⚠️ Limitations

- Works with **text-based PDFs only**; scanned/image PDFs need OCR first.
- Re-creating the database from the web app writes to the same `chroma_db/` folder, so delete it if you want to start fresh with a different document.
- Answer quality depends on how well the retrieved chunks cover the question.
